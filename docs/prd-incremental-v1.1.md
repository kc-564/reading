# 阅读器 App v1.1 增量 PRD

## 产品目标

重构交互架构（三板块底部导航）、修复导入体验（提速 + EPUB）、优化阅读界面交互（可收起面板 + 功能重组），提升整体可用性。

---

## 用户故事

### US-1：多格式快速导入
> "文件导入可能失败，而且很慢，导入的文件包含 TXT 和 EPUB"
- 作为读者，我希望能快速导入 TXT 和 EPUB 文件，不失败不卡顿。
- 验收标准：EPUB 可正常导入并解析章节；导入进度可见；导入失败显示具体原因。

### US-2：导入即用时显示文件名+封面
> "导入文件，书名要显示为文件名，封面显示为文件自带封面"
- 作为读者，我希望导入后书名默认就是文件名（如"三体.txt"→"三体"），如果有内置封面就显示出来。
- 验收标准：书架列表显示文件名为书名；有封面的书显示封面图；无封面显示默认占位图。

### US-3：三板块底部导航
> "软件分为 3 个板块，在下方分为书架，书城，个人"
- 作为读者，我希望底部三个 Tab 能快速切换书架、书城、个人。
- 验收标准：底部导航栏三个 Tab 切换流畅；书城暂时是占位页。

### US-4：个人页面 + 系统设置
> "在个人页面，增加一个设置功能，里面内置一些系统设置"
> "章节识别规则移到系统设置-目录"
- 作为读者，我希望在"个人"页面看到阅读统计、最近阅读、一键进入设置；章节识别规则归属到设置→目录。
- 验收标准：个人页面含"最近阅读"列表（去重）、"阅读统计"入口、"设置"入口；设置页含"目录规则"入口、主题/字体等系统项。

### US-5：阅读界面可收起面板 + 功能重组
> "阅读界面，上下两个功能框做成可收起，当我点击屏幕中间，弹出来"
> "在上面的功能框，右边增加一个折叠起来的功能键，把本书搜索和书签移到那"
> "亮度调节图标改成一个太阳，里面增加功能：亮度调节、背景色，日/夜间模式"
> "把字号等调节页边距等功能、对齐功能、字体另存为一个功能键，放在下方功能框"
- 作为读者，我希望阅读时界面尽量少打扰，点屏幕中间才弹出控制面板。
- 验收标准：默认隐藏上下面板；点击中间区域弹出/收起；顶部右侧有溢出菜单（含搜索、书签）；太阳图标菜单含亮度/背景色/日夜模式；底部有排版功能键（字号/边距/对齐/字体）。

### US-6：最近阅读去重 + 迁移到个人
> "最近阅读移到个人界面"；"最近阅读，当最近连续两本读的书是同一本，那就不要显示两次"
- 作为读者，我希望最近阅读在"个人"页看到，且同一本书连续出现只显示一次。
- 验收标准：个人页的最近阅读列表去重（相邻重复合并）。

## UI 设计要点

### 1. 底部导航（全局）
```
┌──────────────────────────────┐
│         内容区               │
│                              │
├──────────────────────────────┤
│  📚书架    🏪书城    👤个人  │
└──────────────────────────────┘
```
- 书架 Tab：现有 ShelfScreen（含导入 FAB）
- 书城 Tab：占位 Text("即将推出")
- 个人 Tab：最近阅读 + 统计 + 设置

### 2. 阅读界面交互
```
默认状态（无面板）：
┌──────────────────────────────┐
│                              │
│        阅读内容区            │  ← 点中间弹出面板
│                              │
└──────────────────────────────┘

弹出状态：
┌──────────────────────────────┐
│ ←返回   书名          [···] │  ← 顶部栏，[···]溢出菜单：搜索/书签
├──────────────────────────────┤
│                              │
│        阅读内容区            │
│                              │
├──────────────────────────────┤
│ [☀]  [T]  [◀ ▮ ▶]  [排版]  │  ← 底部栏
└──────────────────────────────┘
```
- ☀ = 太阳图标：展开后含亮度滑块、背景色选择、日/夜间模式切换
- T = 当前章节名/进度
- ◀ ▮ ▶ = 上一章/目录/下一章
- 排版键：展开后含字号大小、页边距、对齐方式、字体选择
- 面板 3 秒无操作自动收起（可选）

### 3. 个人页面
```
┌──────────────────────────────┐
│         个人中心              │
├──────────────────────────────┤
│  最近阅读                    │
│  ┌────┐ ┌────┐ ┌────┐      │
│  │封1 │ │封2 │ │封3 │      │  ← 水平滚动，去重
│  └────┘ └────┘ └────┘      │
│  阅读统计 >                  │  ← 点击进入 StatsScreen
│  系统设置 >                  │  ← 点击进入 SettingsScreen
└──────────────────────────────┘
```

### 4. 系统设置页
```
┌──────────────────────────────┐
│  ←返回    系统设置           │
├──────────────────────────────┤
│  主题模式    [浅色/深色/跟随]│
│  默认字体    [系统/思源/...] │
│  目录规则    >               │  ← 迁入原 TocDrawer 内的规则开关
│  关于        v1.0.0          │
└──────────────────────────────┘
```

## 待确认问题（已确认）

1. **EPUB 封面**：无 cover 元数据时 → **使用默认封面**
2. **书城板块**：MVP 阶段 → **纯占位**（"即将推出"）
3. **面板自动收起**：→ **手动点击空白处收起**
4. **TOC 规则**：→ **只在设置里全局改**（阅读页面不显示规则开关）
